做完的事在版本发布时从 [TODO.md](TODO.md) 移入本文件；这里只记录发布结论，不作为待办或部署日志。
版本与日期依据本地发布 tag、提交记录及版本文档。

## 0.x · 公开前原型（2026-09）

完成标准浏览器审阅、三维标注、草稿与版本保护、局域网授权和长期浏览器信任；随后统一界面、国际化、闲置回收，并将核心与 harness 解耦，提供 OpenClaw 扩充、CLI 与 MCP。`v0.4.0-rc.1`（2026-09-10）是候选 tag，不是正式公开发行。

## 1.0.0 · 2026-09-17

首个公开版本，Apache-2.0；标准浏览器中的模型审阅与结构化表面标注，三个入口共用实例管理器，自此承诺公开工具契约稳定。

## 1.0.1 · 2026-09-17

修正文档与陌生用户首次运行的测试准备：CI 生成夹具，缺少非随仓库模型的用例明确跳过，Release 声明来源提交。

## 1.0.2 · 2026-09-18

无材质模型使用审阅灰，修复底面全黑；地面避让模型且从下方不可见，文件自带材质保持不变。

## 1.0.3 · 2026-09-19

降低替补灰亮度，避免高光洗掉细节；同时固定亮暗两端的视觉回归边界。

## 1.1.0 · 2026-09-19

使用 PBR Neutral 重新标定画面与灯光，改善有色模型的明暗和色彩区分；素色与无材质视图共用审阅灰，契约与磁盘数据不变。

## 1.1.1 · 2026-09-20

README 增加真实应用录屏、分享卡与徽章；明确 dev 开发、main 发版的协作规则，产品行为不变。

## 1.2.0 · 2026-09-21

取消指点设备自动识别：滚轮统一缩放，Shift 平移；增加基于 GitHub 的升级提示，只链接发布说明，不代执行升级。

## 1.3.0 · 2026-09-21

支持直接发布 STEP 并转换为审阅网格，保留原文件下载与模型坐标／单位信息。

## 1.3.1 · 2026-09-25

STEP／STL 按 Z-up 显示；补齐 STEP 实体颜色、透明度、毫米单位、重复转换缓存与转换错误诊断。修复方位立方体轨道、安装包完整性与运行版本识别，源码副本可独立启动。

## 1.3.2 · 2026-09-28

更新 README 宣传片、分享卡与公开规划，展示标注、理解回显和新版再审；产品代码与 1.3.1 相同。

## 1.4.0 · 2026-09-30

新增标记短文字、逐标记视角、四种测量与可保留的测量标记，页面显示 Agent 名称及工具。完善提交状态、Telegram 回执与无推送时的读取提示，理解回显改为青色流动虚线；提供预构建 Claude Code 插件。修复区域名、STEP 名称、morph 拒绝与重复加载等边界，并明确 STL 一律灰、颜色使用 STEP／GLB。

## 1.4.1 · 2026-09-30

README 展示 1.4 宣传片并同步安装入口；产品代码与 1.4.0 相同。

## 1.4.2 · 2026-10-09

修复 Windows 启动、缓存校验与 IPC，规范路径和 CRLF 下的 MCP 指引；更新旧版 Claude Code archive 安装提示。真实 Windows CLI、插件、MCP 的审阅提交读取闭环已验证；跨用户与远程访问仍不属于该验证结论。

## 1.5.0 · 2026-10-11

增加零件树、隐藏／隔离／X 光、剖面视图、交互爆炸、显示模式、特征边与整零件标记、智能测量及性能显示；三个 Agent 入口统一契约并提供明确坐标／源模型变换信息。离线支持 Draco、Meshopt、量化 GLB、本地资源 glTF 打包、三角带／扇与显存贴图预算，线／点仍仅提示。所有格式默认 Z-up，GLB 可选 `up:"y"` 恢复 Y-up；此契约变化作为明确批准的 minor 例外，不迁移磁盘数据，不作为后续例外先例。
