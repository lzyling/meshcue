## 用户已确认

| 编号 | 需求                                                                                                                                                                                                                                                                                                                                                                       |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R01  | 本地网页加载模型，支持旋转、缩放预览。                                                                                                                                                                                                                                                                                                                                     |
| R02  | 同一界面支持参数化模型和 Tripo 人偶，不按来源拆成两套工具。                                                                                                                                                                                                                                                                                                                |
| R03  | OpenClaw 将生成的模型交给网页展示，仍负责建模工具调用。                                                                                                                                                                                                                                                                                                                    |
| R04  | 点标签统一使用大写字母 A、B、C、D…，不再提供数字标签选项；落点手势按 R15。同一轮审阅中删除不重排、不复用已分配字母：A/B/C/D 删除 B 后保留 A/C/D，新增点为 E。                                                                                                                                                                                                              |
| R05  | 鼠标画笔、不同颜色标记三维区域；默认只选可见表面，不穿透选择。显示及回传范围必须跟随实际笔迹，不可因触及一个三角面而将整面填色；区域按颜色称呼，不冒充模型上的数字／字母点标签。                                                                                                                                                                                           |
| R06  | 一键反馈编号、位置和标色区域给 OpenClaw。                                                                                                                                                                                                                                                                                                                                  |
| R07  | 用户随后在同一会话用文字说明「A 点怎样改、B 点怎样改」；不依赖开启语音。历史提交仍按其原标签引用，不静默重命名。                                                                                                                                                                                                                                                           |
| R08  | 审阅网页只负责模型显示、标注与提交，移除左侧复制会话及聊天输入框。发起审阅的原会话是唯一对话入口；标注回传、修改说明及 Agent 回复均绑定原会话，不额外复制或分流到另一处。Telegram、Control UI 及未来 ChatGPT App 是不同来源入口，不代表目前已全部适配。                                                                                                                    |
| R09  | 单一大视窗只显示一个当前版本，由 Agent 控制显示与更换；不提供用户自行切换历史版本的主流程，避免模型与标记混淆。                                                                                                                                                                                                                                                            |
| R10  | 网页不同时常驻多份历史模型，保留资源占用限制；单模型规模及切换时的资源释放策略待定。                                                                                                                                                                                                                                                                                       |
| R11  | 提交后 Agent 确认已收到这批标记；若缺少文字说明或标记含义不清，在原会话主动询问，获得足够说明后再修改，不仅凭颜色／编号猜测修改意图。                                                                                                                                                                                                                                      |
| R12  | 用户正在新增或修改标注时，Agent 不得切换／替换当前模型，即使新旧差别很小；保护未提交标注，不让用户做到一半的工作丢失。                                                                                                                                                                                                                                                     |
| R13  | 在用户开始审阅前，由 Agent 负责确保交付并显示正确的最新版本；让用户误在旧版上工作属于 Agent 的版本同步问题，不能要求用户自行识别或承担后果。                                                                                                                                                                                                                               |
| R14  | 正式交互入口统一为用户自己的标准浏览器窗口／标签页，直接渲染模型、处理手势及接收下载。取消 OpenClaw Control UI、Codex、ChatGPT 等 harness 内置浏览器／侧栏／WebView 适配，不以 Portal 替代此要求；原会话与工作台可以并排使用，但不要求同页嵌入。具体浏览器与版本支持范围须验证。此条于 2026-09-10 取代旧侧栏要求。                                                         |
| R15  | 旋转观察与点标签无需切换工具。用户指定触控板／鼠标操作：按住左键拖动旋转模型，对模型表面某点双击落一个标签；普通单击不落标签。取代助手先前提出的单击落标签方案。                                                                                                                                                                                                           |
| R16  | 定位为可适配不同 Agent harness 的通用 3D 审阅与标注工具；核心模型／标注／版本保护与平台接线分责，保留原会话及其 Agent。OpenClaw 为首个实现，不是强制平台。保留其他 harness、MCP、Skill 的工具接线方向，不包含宿主内置浏览器适配；标准浏览器交互与原会话回传分别验收，不将未来方向写作已实现能力。                                                                          |
| R17  | 正式产品只提供面向无开发经验建模用户的一体化安装流程，不设「进阶用户自行组装」选项。不要求用户运行开发命令、编辑配置或分别安装程序／Skill／MCP；依赖、启动、平台工具接线与兼容检查由整合流程处理。安装后从原会话取得标准浏览器入口，不把宿主核心补丁或内置浏览器改造作为安装要求。验收须验证浏览器可操作及原会话回传，不仅是文件落盘。具体安装包、操作系统及版本范围待定， |
| R18  | Agent 理解回显展示其认为要修改的范围，不是改好后的效果图。独立高亮层可隐藏，保留用户原标注与模型，原会话附简明解释；定位不准先澄清，不伪造选区。高亮出现不改变当前视角，用户主动点击「睇修改範圍」才定位。                                                                                                                                                                 |
| R19  | 提供全局显示／隐藏切换按钮：一次点击收起全部用户点标签、涂抹笔迹及 Agent 理解高亮，再次点击恢复显示，方便预览干净模型，不必逐项操作。隐藏属于临时显示状态，不删除标注、取消修改要求或过滤提交内容；模型及原有标注数据保留。                                                                                                                                                |
| R20  | 用户误删标记后可以撤销删除；恢复的是同一个原标记，保留原字母、位置及标注数据，不重新分配字母、不当成新增点。例如删除 B 后撤销，恢复的仍是 B，其他标签不重排。基础撤销重做已有实现，本条为用户确认的字母标识保留要求，须随新设计集中核验，                                                                                                                                  |
| R21  | 提供可收合的标注清单，便于标记较多时查找，并可收起清单腾出模型显示空间。点选清单中的 C 只高亮对应 C 标记，不改变视角；用户另行点击「定位」才移动视角查看该标记。此为用户已采纳的设计，                                                                                                                                                                                     |
| R22  | 提交回馈明确区分「已保存」「已送到原会话」「Agent 已读取」，每一状态都须由对应事实／真实回执支持；不因用户点击提交、经过一段时间或前一步成功就宣称后一步完成。Agent 已读取不等于已理解、已开始改模或修改完成。用户已采纳此设计，                                                                                                                                           |
| R23  | 提交后仍可继续新增或修改标记，但已提交的那批内容保持不变。后续改动留在当前草稿并显示「尚未提交」，必须由用户再次点击提交才交给 Agent，不自动送出。保存草稿与发送到原会话分开；旧批次的送达／已读回执不表示新改动已经提交。用户已确认。                                                                                                                                     |
| R24  | 画笔可切换为标注橡皮擦，局部擦除已经画上的标注笔迹，不必删除整个色区；只改标注涂色，不破坏模型几何或原始材质。用户已确认需要此功能，                                                                                                                                                                                                                                       |
| R25  | 增加标注油漆桶，一次填色一片表面，而不是仅填单个三角面。相邻三角面衔接方向差很小时可跨面扩张，同时限制候选面相对最初点中面的方向偏差，避免沿平滑曲面因局部小角度累计而越填越远。两项角度条件须同时满足；不要求严格数学共面。填色属于标注层，不改模型原材质。此范围规则已获用户确认；具体容差及遮挡等细节待定，                                                             |
| R26  | 支持标签重新定位：在清单选择某标签的重新定位操作，再点击模型上的正确位置，移动的是同一个标签，保留其字母与标识，不先删除再创建。例如 B 移动后仍是 B。操作放在清单内，不另加常驻工具按钮；已提交批次保持原样，新位置按 R23 留草稿、再次手动提交才送出。用户已采纳，                                                                                                         |
| R27  | 页面布局以模型预览为主要工作空间：明显缩小顶部标题区，压缩上下留白及其他非必要纵向占位，避免模型窗口被推到页面下方或过小；在标准浏览器普通窗口或并排窄窗口内尽量扩大模型预览区域。保留响应式布局，不将窄窗口支持等同宿主侧栏适配；具体手感须实测。                                                                                                                         |
| R28  | 提供直接下载当前预览版本的按钮。用户审阅满意后可自行取得眼前这版模型，不必再要求 Agent 整理文件；下载目标绑定当前实际显示的模型版本，而不是后台最新、待发布或其他历史版本。下载不代表提交标注、结束审阅或切换模型，不要求该版本先被标为最终版。用户已明确提出。                                                                                                            |
| R29  | 审阅对象不只素体：带着色／贴图的模型保留原有颜色与材质外观，以原色预览为主要模式；标注通过图案及对比描边等与原色区分，不只依赖颜色。支持自选的素色辅助检视，不强制替代原色审阅；标注及检视模式均不改写原材质或下载文件。用户已采纳此呈现方向，具体样式待细化及试用，                                                                                                       |

**R30 · 原对话中的可用链接交付（2026-09-10 用户明确）**：用户在 Telegram 发起对话，Agent 在同一对话提供能顺利进入模型预览的网站地址；不要求转到 Control UI 或适配其界面。入口须在用户实际设备／网络加载正确模型，不能以仅服务主机可用的地址冒充交付；标注及回复仍按 R08 回原话题。内网访问已按 R31 明确，公网／外出跨网络未确认；详见 [入口决策](BROWSER-ACCESS-DECISION.md)。

## 后续确认的需求

- **R31 · 局域网授权**：运行服务的电脑为同一局域网的另一台电脑提供受保护入口；核对客户端地址后签发一小时一次性许可，浏览器三十天闲置授权，正常操作续期、重启保留。新未用许可替代旧许可，不打断活跃编辑或清除草稿；不通过链接传凭据，不增加配对。见 [LAN-ADMISSION](LAN-ADMISSION.md)。
- **R32 · 工具栏与版本**：隐藏标注／素色查看使用工具栏开关，版本靠近品牌并显示运行版本；清单折叠时收起提交入口，语言／明暗使用可访问图标。指点设备识别后来由 1.2.0 统一滚轮操作取代。
- **R33 · 紧凑布局**：取消额外模型信息行的视觉占位，必要信息保留可访问语义；方向立方靠上，工具栏开关有简短名称，清单折叠只留展开按钮。
- **R34 · 不提供降级档**：源面标记不依赖细分预算，不因预算耗尽要求无谓简化。硬上限保留；细分本身的纯性能开销另行评估，不能删除源面映射。

## 验收原则

标准浏览器完整操作、原会话回传、草稿与版本锁、不可变提交、当前版本原文件下载分别验证。保存、送达、读取均需真实证据，不以一种浏览器或路由通过推断全部平台兼容。结构化位置与模型版本为主，截图仅辅助；原材质与标注分离，重拓扑不复用旧索引。
