# MeshCue · 标准浏览器入口决策

维护者于 2026-09-10 决定：正式入口是用户自己的标准浏览器，取消宿主内置浏览器、侧栏和 WebView 适配；跨 harness 的 Agent 接线保留。

## 产品入口

- Agent 从原会话交付可达网址；网页负责模型显示、标注、回显与下载，原会话负责对话，不复制聊天框。
- 工作台运行于运行服务的电脑；同一局域网的另一台电脑通过受保护的入口访问。回环地址只用于服务所在电脑，公网不是已承诺范围。
- 用户打开普通链接，不输入凭据、不配对；Agent 核对客户端 IPv4 后签发许可，浏览器自动领取 HttpOnly cookie。链接、聊天和日志不含访问凭据。
- 首次许可一小时、单次使用；新许可替代旧未用许可，不打断活跃编辑。浏览器三十天闲置失效、实际操作续期、重启保留，见 [浏览器信任](BROWSER-TRUST.md) 与 [局域网入场](LAN-ADMISSION.md)。

## 保护与交付

模型、贴图、下载、草稿、提交与状态统一鉴权；入口壳不代表授权。Host／Origin／自定义标头是来源与 CSRF 辅助检查，不替代 cookie。本地 Agent 管理入口与网页隔离，授权失效不删草稿或版本锁。

独立工作台不依赖宿主截图、输入或下载中转补丁，扩充仅负责接线与交付；平台自身的加载要求不作统一承诺。

## 验收

1. 在用户浏览器核对正确模型并完整操作，分别验证普通及并排窄窗口。
2. 提交携带模型身份、三维位置和批次，回正确原会话；保存、送达、读取分别需要证据。
3. 下载取得点击时显示版本的原文件，保留材质、不含覆盖层、不改变草稿或锁。
4. 验证资源鉴权、许可轮换、到期、跨标签页及重启恢复；一种浏览器或路由通过不能推广到全部兼容矩阵。
