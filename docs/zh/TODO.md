# MeshCue · 待办

本文件只记录接下来要做的事。做完的事在版本发布时从 TODO 移进 [ROADMAP.md](ROADMAP.md)。
当前版本以 `package.json` 为准；版本判定遵守 [VERSIONING.md](VERSIONING.md)。

## 版本规划

面向实体生产的机械类模型审阅，长期迭代 1.x；所有新增字段／action 必须向后兼容，旧数据不迁移。
目标 30 FPS，以实际设备验证；不采用操作时降载、停手补回的自动降级。性能显示应可开关，展示 FPS、帧时间、三角形数。
版本规划规定顺序和范围，不是发布日期承诺；无法保持兼容的变化须单独评审。

- **1.5.0 已发布（2026-10-11）**：装配树、剖面视图、交互爆炸及显示模式，结论见 ROADMAP。

**排期原则**：只把技术上确定能做到的功能排进版本；交互细节未定但做得到的，照样排入。可行性未知的写进下方「远景」，不占版本号。缺陷修正、打包、文案和不改行为的重构走 patch（1.5.1、1.5.2……），不等功能版本。

### 1.6 · 版本分支树＋特征识别

- 同一模型按版本树组织；从旧节点另做时保留停止推进的旧分支，分叉有标志且可重新显示。
- 底部图标时间线、游标回看、悬浮步骤说明；具体呈现与交互在本版开发时讨论。
- 版本／分支与所选旧节点的标记上下文共享给 Agent，确保修改指定旧版。
- 不自动扩展分支合并、完整 PDM 或 CAD 特征重算。
- 识别孔（含沉头、埋头）、凹槽、凸台、圆角；标记带特征并支持按特征选择。可参考 text-to-cad 的浏览器 STEP 实现，遵守 MIT 许可并保留原声明。
- 本版建立的 STEP 面相邻关系供 1.7 连面选择复用。

### 1.7 · Agent 标注图层＋GLB 收尾＋连面选择

- Agent 独立标注图层，用于风险和提问；人可直接回复，样式与人类标注、理解回显区分。检查计算由外部工具负责。
- 机械装配 GLB：原定压缩／量化、本地资源 `.gltf` 打包、三角带／扇、显存贴图预算已在 1.5.0 发布，不重复开发；剩余范围开工时重核。线／点维持仅提示。
- 不直接打开 3MF：Agent 先转换；多零件或多色优先 GLB，单件单色可 STL。核对并补齐 Skill 指引。
- 沿相切面一次选择整圈（如圆角）；特征边、整零件／组标记已在 1.5.0 发布，不重复实施。不加入空白处三维草图，不照搬仅存于截图的二维 Draw。

### 1.8 · 机械关节与姿态

- 声明沿用 text-to-cad 的 `{mates, couplings, poses}`：转动、滑动、圆柱副与固定，每个活动关节必须给出有限行程；联动为线性比例；姿势为命名预设。关节构成树，只做正向运动学，不含求解器。
- 关节由 Agent 随模型发布声明；Skill 与 Agent 契约同步说明写法，作为可选新增字段，旧数据照读。
- 滑杆／拖动把手查看行程，可切换和命名姿势；标记记住姿势。
- 活动／姿势下提示零件干涉；大装配先粗筛再细查，性能以实测为准。

### 1.9 · 仿真结果图层

- MeshCue 不内置求解器：温度、应力、安全系数等由 Agent 用外部工具算好，随模型发布逐点数值。
- 按数值着色并显示色标；点任意位置读数；可在热点上直接标记，Agent 读回位置与数值。
- 发光部件：显示自发光材质与辉光，Agent 可声明光源的颜色与亮度。
- 数据格式与体积上限在开工时定，守住 30 FPS 目标。

## 远景

可行性未知，不占版本号。须先验证可行，并经维护者同意，才排进版本。

- **服务端截图自查**：按指定视角、剖面、爆炸、隐藏或姿势出图，可带标记；须证明不打包 Chromium 也能出图。
- **text-to-cad 引用互通**：验证 cadgen 编号能否与 STEP 面一一对应；对应才在 `read` 附引用。
- **闭环机构**：四连杆等需要约束求解的机构。
- **从 STEP 装配约束自动读出关节**，免去 Agent 另写声明。
- **发热示意动效**：在仿真结果图层之上，为热源加热浪、扩散光晕等演示动画。
- **CFD 粒子流动**：Agent 导出流线或采样速度场，MeshCue 以粒子沿流线运动显示；须先定精简的交换格式，并验证粒子数与 30 FPS 的平衡。

## 后备候选

有真实需求并经维护者同意才升格，不排进版本开发。

- 动画片段选择、播放／暂停、时间轴／逐帧；标记带时间点；截图某帧与整段视频；解决仅初始姿势显示。其他格式先转 GLB 的方案待定。
- 游戏／网格向运动学声明、关节与联动、命名姿势、姿势标记与干涉、指定姿势截图，不混入机械关节版的已定范围。
- 骨骼绑定姿势、morph 基础形状；目前继续拒绝 `ANIMATED_MODEL`。
- GLB 线／点显示：若升格，仅显示、不可标记、不进零件树；当前只提示未显示数量。

## 不在当前产品目标内

- 游戏资产／游戏美术审阅：UV、棋盘格、材质通道检视、分网格面数；不是后备候选。
- 游戏管线 LOD、材质变体、KTX2／BasisU、GPU instancing、WebP／AVIF 扩展兼容与文件灯光专门处理，不纳入现行规划。
